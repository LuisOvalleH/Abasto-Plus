# Abasto Plus

TypeScript backend experiment for inventory and supply workflows. The project uses dependency injection, MongoDB, and an OpenAI integration layer as part of a modular backend architecture.

## Tech Stack

- TypeScript
- Node.js
- MongoDB
- Inversify
- OpenAI SDK

## Project Structure

```text
src/      Application source code
dist/     Compiled output
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run the project according to the scripts and entry points defined in the source code.

## Notes

This repository is an active backend experiment. The documentation should be expanded as modules, scripts, and deployment steps become stable.
